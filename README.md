## About MathSphere

**MathSphere** is a mathematics and calculator application built with Flutter and Dart. It brings together useful mathematical tools in one place, helping students and users perform calculations and explore mathematical concepts.

The project focuses on scientific calculations, geometry, unit conversions, financial calculations, and graph plotting.

Whether you're studying mathematics, solving everyday calculation problems, or exploring mobile app development, MathSphere aims to make mathematical tools more accessible.

## Features

- **Scientific Calculator:** Perform scientific and mathematical calculations.
- **Geometry Tools:** Explore calculations related to geometric shapes.
- **Unit Converter:** Convert supported measurement units.
- **Financial Calculators:** Perform supported financial calculations.
- **Graph Plotting:** Visualize supported mathematical functions.
- **Student Productivity:** Access useful mathematical tools in one application.
- **Flutter-Based UI:** A mobile application built with Flutter and Dart.

*The exact calculators and supported operations depend on the current implementation.*

## Getting Started

Follow these steps to set up MathSphere locally.

### Prerequisites

Install the following tools:

- [Flutter SDK](https://docs.flutter.dev/get-started/install)
- [Dart SDK](https://dart.dev/get-dart) (included with Flutter)
- [Android Studio](https://developer.android.com/studio) or [Visual Studio Code](https://code.visualstudio.com/)
- An Android emulator or compatible physical device

Verify your Flutter installation:

```bash
flutter doctor
```

### Installation

**1. Clone the repository**

```bash
git clone https://github.com/abhayguptadev/MathSphere.git
```

**2. Navigate to the project directory**

```bash
cd MathSphere
```

**3. Install dependencies**

```bash
flutter pub get
```

**4. Check available devices**

```bash
flutter devices
```

**5. Run the application**

```bash
flutter run
```

Make sure your emulator or physical device is connected and recognized by Flutter.
