# 🌌 MathSphere – The Ultimate Mathematical Suite

MathSphere is a modern Flutter application that brings together powerful mathematical calculators, graphing tools, financial utilities, and note-taking features in one place. It is designed for students, engineers, teachers, and professionals who need a fast, organized, and reliable mathematics toolkit.

## 🎯 Overview

Instead of switching between multiple applications for calculations, graphing, financial planning, and formulas, MathSphere combines everything into a single, easy-to-use platform.

The app focuses on speed, simplicity, and privacy by storing all user data locally on the device.

## 🔒 Privacy

MathSphere stores all calculations, notes, formulas, and history locally using Hive.

No cloud storage.
No account required.
Your data stays on your device.
